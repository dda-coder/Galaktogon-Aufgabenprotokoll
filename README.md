# GALAKTOGON Aufgabenprotokoll (GAP)

Das GALAKTOGON Aufgabenprotokoll ist eine Web-App, mit der ich meine Aufgaben und Termine organisieren kann. Das Projekt habe ich selbst aufgebaut und entwickle es nach und nach weiter.

## Was kann das GAP?

- Sektoraufgaben, Sektorprüfungen und eigene Quests verwalten
- Aufgaben und Termine im Tagesplan anzeigen
- XP sammeln und dadurch Ränge erreichen
- Wiederkehrende Aktivitäten eintragen
- Ein Elternkonto mit einem Kinderkonto verbinden
- Daten sichern und wiederherstellen
- Die Ansicht anpassen, zum Beispiel für kleinere Bildschirme

## Technik

Das Projekt ist mit HTML, CSS und JavaScript umgesetzt. Für die Anmeldung und die Datensynchronisierung wird Supabase verwendet. Die Web-App ist außerdem für die Nutzung auf mobilen Geräten ausgelegt.
